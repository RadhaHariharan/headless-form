# Security Policy

## Supported Versions

This project has not yet reached a stable 1.0 release for most packages. Security fixes are
made against the latest published version of each `@headlesskit/*` package on npm — there is
currently no separate maintenance branch for older versions.

| Package | Supported |
|---------|-----------|
| Latest version of any `@headlesskit/*` package on npm | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or
pull requests.**

Instead, report them privately using one of the following methods:

1. **Preferred:** open a
   [GitHub Security Advisory](https://github.com/RadhaHariharan/headlesskit/security/advisories/new)
   for this repository. This notifies maintainers directly and keeps the report private until
   a fix is ready.
2. If you're unable to use GitHub Security Advisories, open a regular issue asking a maintainer
   to provide an alternate contact, without including any vulnerability details in the issue
   itself.

When reporting, please include as much of the following as you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof-of-concept
- The affected package(s) and version(s)
- Any known mitigations or workarounds

## What to expect

- We aim to acknowledge new reports within **5 business days**.
- We'll work with you to understand and confirm the issue, and aim to ship a fix or mitigation
  as quickly as the severity warrants.
- We'll credit reporters in the fix's release notes / GitHub Security Advisory, unless you'd
  prefer to remain anonymous.
- Once a fix is published, we'll publicly disclose the advisory with details, generally after
  a reasonable window for users to upgrade.

Thank you for helping keep headlesskit and its users safe.
