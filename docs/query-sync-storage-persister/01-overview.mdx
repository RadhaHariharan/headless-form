# Query Sync Storage Persister

`@headlesskit/query-sync-storage-persister` creates a `Persister` backed by any synchronous storage — `localStorage`, `sessionStorage`, or any object satisfying the `Storage` interface. It throttles writes to avoid hammering storage on every cache update, and supports a retry strategy for handling storage quota errors.

```bash
pnpm add @headlesskit/query-sync-storage-persister
```

Requires `@headlesskit/query-persist-client-core` for the `persistQueryClient` lifecycle functions.

---

## createSyncStoragePersister

```typescript
import { createSyncStoragePersister } from '@headlesskit/query-sync-storage-persister';

const persister = createSyncStoragePersister({
  storage: window.localStorage,
});
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `storage` | `Storage \| null \| undefined` | required | Synchronous storage backend. If `null` or `undefined`, a no-op persister is returned. |
| `key` | `string` | `'REACT_QUERY_OFFLINE_CACHE'` | Storage key for the serialized snapshot |
| `throttleTime` | `number` | `1000` | Minimum ms between write operations |
| `serialize` | `(client: PersistedClient) => string` | `JSON.stringify` | Serializer |
| `deserialize` | `(str: string) => PersistedClient` | `JSON.parse` | Deserializer |
| `retry` | `(client, error) => PersistedClient \| undefined` | — | Called when `setItem` throws (e.g. quota exceeded). Return a modified client to retry, or `undefined` to give up. |

### Storage interface

```typescript
interface Storage {
  getItem(key: string): string | null;
  setItem(key: string, value: string): void;
  removeItem(key: string): void;
}
```

`window.localStorage` and `window.sessionStorage` both satisfy this interface directly.

## Usage

### localStorage

```typescript
import { QueryClient } from '@headlesskit/query-core';
import { persistQueryClient } from '@headlesskit/query-persist-client-core';
import { createSyncStoragePersister } from '@headlesskit/query-sync-storage-persister';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      gcTime: 1000 * 60 * 60 * 24, // 24h — keep data in memory long enough to persist
    },
  },
});

const persister = createSyncStoragePersister({
  storage: window.localStorage,
  key: 'MY_APP_CACHE',
  throttleTime: 1000,
});

const [unsubscribe, restorePromise] = await persistQueryClient({
  queryClient,
  persister,
  maxAge: 1000 * 60 * 60 * 24, // 24h
  buster: import.meta.env.VITE_BUILD_HASH ?? '',
  onSuccess: () => {
    console.log('Cache restored from localStorage');
  },
});

await restorePromise;
queryClient.mount();
```

### sessionStorage (per-tab cache)

```typescript
const persister = createSyncStoragePersister({
  storage: window.sessionStorage,
  key: 'SESSION_CACHE',
  throttleTime: 0, // write immediately — session storage is cheap
});
```

### subscribe-only (no await)

```typescript
import { persistQueryClientSubscribe } from '@headlesskit/query-persist-client-core';

const unsubscribe = persistQueryClientSubscribe({
  queryClient,
  persister,
  buster: 'v1',
  onSuccess: () => refetchStaleQueries(),
});
```

## Handling storage quota exceeded

`localStorage` has a 5–10 MB limit depending on browser. When the serialized snapshot exceeds this, `setItem` throws a `QuotaExceededError`. Use the `retry` option to recover by reducing what you persist:

```typescript
import { createSyncStoragePersister } from '@headlesskit/query-sync-storage-persister';
import type { PersistedClient } from '@headlesskit/query-persist-client-core';

const persister = createSyncStoragePersister({
  storage: window.localStorage,
  retry: (persistedClient: PersistedClient, error: Error) => {
    // On quota error, keep only the 10 most recently used queries
    const trimmed: PersistedClient = {
      ...persistedClient,
      clientState: {
        ...persistedClient.clientState,
        queries: persistedClient.clientState.queries
          .sort((a, b) => (b.state.dataUpdatedAt ?? 0) - (a.state.dataUpdatedAt ?? 0))
          .slice(0, 10),
      },
    };
    return trimmed;
  },
});
```

The `retry` function is called in a loop:
1. `persistedClient` is the client that failed to save.
2. Return a modified (smaller) `PersistedClient` to retry.
3. Return `undefined` to give up (the write is abandoned silently).

The loop continues until the save succeeds or `retry` returns `undefined`.

## Custom serialization

For handling special types or reducing serialized size:

```typescript
import SuperJSON from 'superjson';

const persister = createSyncStoragePersister({
  storage: window.localStorage,
  serialize: SuperJSON.stringify,
  deserialize: SuperJSON.parse,
});
```

```typescript
// Selective query persistence via dehydrateOptions
import { persistQueryClient } from '@headlesskit/query-persist-client-core';

await persistQueryClient({
  queryClient,
  persister,
  dehydrateOptions: {
    // Only persist queries you explicitly mark
    shouldDehydrateQuery: (query) =>
      query.state.status === 'success' &&
      (query.meta as any)?.persist === true,
  },
});
```

Then on individual queries:

```typescript
queryClient.fetchQuery({
  queryKey: ['user-profile'],
  queryFn: fetchProfile,
  meta: { persist: true },  // this one will be persisted
});
```

## Custom in-memory storage

Useful in SSR, tests, or environments without `window`:

```typescript
const memoryStore = new Map<string, string>();

const persister = createSyncStoragePersister({
  storage: {
    getItem: (key) => memoryStore.get(key) ?? null,
    setItem: (key, value) => memoryStore.set(key, value),
    removeItem: (key) => memoryStore.delete(key),
  },
});
```

---

## Null-safe storage

Passing `null` or `undefined` as `storage` returns a no-op persister:

```typescript
const persister = createSyncStoragePersister({
  storage: typeof window !== 'undefined' ? window.localStorage : null,
});
// Safe in SSR — no errors, no persistence
```

## Comparison: sync vs async persister

| | `createSyncStoragePersister` | `createAsyncStoragePersister` |
|---|---|---|
| Storage type | Synchronous (`localStorage`, `sessionStorage`) | Asynchronous (`AsyncStorage`, IndexedDB) |
| Write throttle | `setTimeout`-based | Async-aware throttle |
| Retry on failure | `retry` callback | — |
| Platform | Browser only | Browser + React Native |
| Typical use | Web apps | React Native, PWA with IndexedDB |
