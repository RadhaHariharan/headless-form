# DockMonitor

**File:** `src/dock-monitor.tsx`

The dockable panel chrome on its own — a floating toggle button when closed, a panel docked to one edge of the viewport (with a position switcher and close button) when open. Unrelated to the lifted-state engine; pure UI shell around whatever `children` you pass.

```tsx
import { DockMonitor } from '@headlesskit/state-management-devtools-react';
```

## Signature

```typescript
interface DockMonitorProps {
  dockStore: DockStore; // from installDevtools()
  children: ReactNode;  // typically an Inspector
}

function DockMonitor(props: DockMonitorProps): JSX.Element
```

## Basic usage

```tsx
<DockMonitor dockStore={dockStore}>
  <Inspector inspectorStore={inspectorStore} />
</DockMonitor>
```

This is exactly what [`DevtoolsPanel`](./02-devtools-panel.mdx) does — use `DockMonitor` directly if you want the same dockable chrome around different content.

## Common pitfalls

- **Position and size come entirely from `dockStore`** — there's no `position`/`size` prop on `DockMonitor` itself; call `dockStore.setPosition(...)`/`dockStore.setSize(...)` (or click the built-in position buttons) to change them.
