# DevtoolsPanel

**File:** `src/devtools-panel.tsx`

The convenience component most apps use — a `DockMonitor` wrapping an `Inspector`.

```tsx
import { DevtoolsPanel } from '@headlesskit/state-management-devtools-react';
```

## Signature

```typescript
interface DevtoolsPanelProps {
  inspectorStore: InspectorStore; // from installDevtools()
  dockStore: DockStore;           // from installDevtools()
}

function DevtoolsPanel(props: DevtoolsPanelProps): JSX.Element
```

## Basic usage

```tsx
import { DevtoolsPanel } from '@headlesskit/state-management-devtools-react';
import { inspectorStore, dockStore } from './devtools-setup';

<DevtoolsPanel inspectorStore={inspectorStore} dockStore={dockStore} />
```

## Common pitfalls

- **If you need the toolbar/list/tabs without the floating dock chrome** (e.g. embedding the panel in your own layout instead of a fixed overlay), render [`Inspector`](./03-inspector.mdx) directly instead of `DevtoolsPanel`.
