# exportLiftedState and importLiftedState

**File:** `src/export-import.ts`

The Export/Import buttons in [`InspectorToolbar`](./04-inspector-toolbar.mdx) are thin wrappers around these two functions, exported in case you want to build your own import/export UI.

```typescript
import { exportLiftedState, importLiftedState } from '@headlesskit/state-management-devtools-react';
```

## Signature

```typescript
function exportLiftedState(connectionName: string, liftedState: LiftedState): void
function importLiftedState(file: File): Promise<LiftedState>
```

## What each does

- `exportLiftedState` serializes a `LiftedState` to pretty-printed JSON, creates a `Blob` URL, and clicks a hidden `<a download>` to trigger a browser download named `<connectionName>-devtools-export.json`. Revokes the blob URL immediately after.
- `importLiftedState` reads a `File` (e.g. from a file input's `onChange`) via `FileReader`, parses it as JSON, and returns it typed as `LiftedState`. It does **not** validate the shape — a syntactically valid JSON file that isn't actually a `LiftedState` will parse successfully and likely break `Inspector` rendering. The caller (`InspectorToolbar`) is responsible for catching parse failures and surfacing an error.

## Basic usage

```typescript
exportLiftedState('counter', inspectorStore.getSnapshot().connections.counter);

// elsewhere, from a <input type="file" onChange={...}>
const file = event.target.files[0];
const liftedState = await importLiftedState(file);
inspectorStore.importState('counter', liftedState);
```

## Common pitfalls

- **Re-importing a history doesn't validate against the connection's current `step` function.** If you import a `LiftedState` recorded by a different reducer (or a different version of your reducer), `inspectorStore.importState` will recompute it with *today's* reducer — actions may replay to different results than when they were originally recorded.
- **`importLiftedState` rejects on read failure or invalid JSON** — wrap calls in try/catch (or a `.catch()`), as `InspectorToolbar` does.
