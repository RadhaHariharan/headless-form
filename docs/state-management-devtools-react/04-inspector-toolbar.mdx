# InspectorToolbar

**File:** `src/inspector-toolbar.tsx`

The command toolbar rendered at the top of [`Inspector`](./03-inspector.mdx) — connection picker, Record/Lock toggles, and every time-travel command.

```tsx
import { InspectorToolbar } from '@headlesskit/state-management-devtools-react';
```

## Signature

```typescript
interface InspectorToolbarProps {
  inspectorStore: InspectorStore;
  connectionNames: string[];
  activeName: string | undefined;
  onSelectConnection: (name: string) => void;
  liftedState: LiftedState | undefined;
}

function InspectorToolbar(props: InspectorToolbarProps): JSX.Element
```

## Buttons

| Button | Calls | Disabled when |
|--------|-------|----------------|
| Record / Pause | `inspectorStore.pause(name, !isPaused)` | no active connection |
| Lock | `inspectorStore.lock(name, !isLocked)` | no active connection |
| Reset | `inspectorStore.reset(name)` | no active connection |
| Revert | `inspectorStore.revert(name)` | no active connection, or no staged actions |
| Sweep | `inspectorStore.sweep(name)` | no active connection, or nothing is skipped |
| Commit | `inspectorStore.commit(name)` | no active connection |
| Export | downloads the active connection's `LiftedState` as JSON (via [`exportLiftedState`](./07-export-import.mdx)) | no active connection |
| Import | opens a hidden file picker; on a valid file, calls `inspectorStore.importState(name, parsed)` (via [`importLiftedState`](./07-export-import.mdx)); on an invalid file, shows an inline error message | no active connection |
| Print | `window.print()` | never |
| Clear | `inspectorStore.clear(name)` | no active connection |

The connection `<select>` only renders when `connectionNames.length > 1`.

## Basic usage

You won't usually render this directly — it's the toolbar half of [`Inspector`](./03-inspector.mdx), which manages `activeName`/`onSelectConnection` for you.

## Common pitfalls

- **Import failures are shown inline, not thrown or logged** — invalid JSON (or JSON that doesn't parse to a `LiftedState`) produces a message next to the toolbar buttons instead of a console error.
- **Print prints the whole page**, not just the panel — there's no print-specific stylesheet scoping it to the devtools panel alone.
