# JsonTree, DiffTree, and computeDiff

**Files:** `src/json-tree.tsx`, `src/diff-tree.tsx`, `src/compute-diff.ts`

The rendering pieces behind the Action/State tabs' Tree view (`JsonTree`) and the Diff tab's Tree view (`DiffTree`, fed by `computeDiff`).

```tsx
import { JsonTree, DiffTree, computeDiff, countChanges } from '@headlesskit/state-management-devtools-react';
```

## JsonTree

```typescript
interface JsonTreeProps {
  value: unknown;
  label?: string;
  defaultExpanded?: boolean; // default true
}

function JsonTree(props: JsonTreeProps): JSX.Element
```

Renders any value as a collapsible, color-coded tree: objects and arrays show a summary (`Object(n)` / `Array(n)`) and expand to their entries; primitives render inline with type-based coloring (strings, numbers, booleans, and `null`/`undefined` each get a distinct color). Click the arrow (or the summary text) to expand/collapse a nested node — each node manages its own expanded state independently, defaulting to collapsed except the root.

## computeDiff(prev, next) and countChanges(nodes)

```typescript
interface DiffNode {
  key: string;
  status: 'added' | 'removed' | 'changed' | 'unchanged';
  prevValue?: unknown;
  nextValue?: unknown;
  children?: DiffNode[]; // present when both values at this key are objects/arrays
}

function computeDiff(prev: unknown, next: unknown): DiffNode[]
function countChanges(nodes: DiffNode[]): number
```

`computeDiff` walks both values' keys (the union of `Object.keys(prev)` and `Object.keys(next)`), classifying each as added/removed/changed/unchanged, recursing into nested objects/arrays. If either input isn't an object/array, it returns a single `'(root)'` node comparing the two values directly. `countChanges` recursively counts non-`'unchanged'` nodes — useful for a badge like "3 changes" without rendering the tree.

## DiffTree

```typescript
interface DiffTreeProps {
  nodes: DiffNode[];
}

function DiffTree(props: DiffTreeProps): JSX.Element
```

Renders a `computeDiff` result with `+`/`−` markers for added/removed fields and a `prev ⇒ next` format for changed ones. Shows only the changed fields when at least one exists; falls back to showing every field (all `'unchanged'`) when nothing changed, so an action with no effect still renders something instead of an empty panel.

## Basic usage

```tsx
const nodes = computeDiff(previousState, currentState);
<DiffTree nodes={nodes} />
```

## Common pitfalls

- **`computeDiff` only diffs object/array structure, not array order or identity.** An array reordered without any element changing shows as "unchanged" per-index, which can look surprising if you expected index-shift highlighting like a text diff.
- **Values that can't be `JSON.stringify`-d (circular references, etc.) fall back to `String(value)`** in `DiffTree`'s rendering — this is a display fallback only, `computeDiff` itself never serializes.
