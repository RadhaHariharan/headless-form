# Query Devtools

`@headless-form/query-devtools` is a framework-agnostic devtools panel for inspecting and debugging `@headless-form/query-core` cache state. It renders a shadow-DOM-isolated UI overlay that shows all queries, their status, data, errors, and timing — and lets you trigger refetches or remove queries manually.

```bash
pnpm add @headless-form/query-devtools
```

---

## QueryDevtools

The main devtools class. Mount it once, passing a `QueryClient`. It creates and manages its own DOM tree in a shadow root so styles cannot leak into or from your app.

```typescript
import { QueryDevtools } from '@headless-form/query-devtools';
import { queryClient } from './queryClient';

const devtools = new QueryDevtools({
  client: queryClient,
  initialIsOpen: false,
});
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `client` | `QueryClient` | required | The `QueryClient` instance to observe |
| `initialIsOpen` | `boolean` | `false` | Whether the panel starts open |
| `buttonPosition` | `ButtonPosition` | `'bottom-right'` | Position of the toggle button |
| `position` | `PanelPosition` | `'bottom'` | Which edge the panel docks to |
| `onClose` | `() => void` | — | Callback when the panel is closed |
| `errorTypes` | `{ name: string; initializer: (query) => Error }[]` | — | Custom error types for the error picker |
| `styleNonce` | `string` | — | CSP nonce for injected `<style>` tags |
| `shadowDOMTarget` | `ShadowRoot` | — | Mount into an existing shadow root |
| `theme` | `Theme` | auto | `'light'` or `'dark'` |
| `sort` | `SortFn` | by query key | Custom sort function for the query list |

### ButtonPosition

```typescript
type ButtonPosition =
  | 'top-left'
  | 'top-right'
  | 'bottom-left'
  | 'bottom-right'
  | 'relative';
```

`'relative'` renders the toggle button inline in your layout instead of as a fixed overlay.

### PanelPosition

```typescript
type PanelPosition = 'top' | 'bottom' | 'left' | 'right';
```

## Mounting and destroying

```typescript
import { QueryDevtools } from '@headless-form/query-devtools';
import { queryClient } from './queryClient';

let devtools: QueryDevtools | undefined;

if (process.env.NODE_ENV !== 'production') {
  devtools = new QueryDevtools({
    client: queryClient,
    initialIsOpen: false,
    buttonPosition: 'bottom-right',
    position: 'bottom',
  });
}

// Later (e.g. on app teardown)
devtools?.destroy();
```

`destroy()` removes the shadow host element from the DOM and cleans up all subscriptions.

## Updating options at runtime

All constructor options can be changed after mounting via `setOptions`:

```typescript
devtools.setOptions({
  initialIsOpen: true,
  position: 'right',
  theme: 'dark',
});
```

## Custom sort

Control the order queries appear in the panel:

```typescript
import type { SortFn } from '@headless-form/query-devtools';

const sortByUpdatedAt: SortFn = (a, b) =>
  b.state.dataUpdatedAt - a.state.dataUpdatedAt;

const devtools = new QueryDevtools({
  client: queryClient,
  sort: sortByUpdatedAt,
});
```

`SortFn` receives two `Query` objects and follows standard comparator conventions (`< 0` = `a` first, `> 0` = `b` first, `0` = equal).

## Custom error types

Add custom errors to the devtools "trigger error" dropdown. Useful for testing error states in development:

```typescript
const devtools = new QueryDevtools({
  client: queryClient,
  errorTypes: [
    {
      name: '404 Not Found',
      initializer: (query) => {
        const error = new Error(`Not found: ${String(query.queryKey)}`);
        (error as any).status = 404;
        return error;
      },
    },
    {
      name: '500 Server Error',
      initializer: () => new Error('Internal server error'),
    },
  ],
});
```

## CSP nonce

If your Content Security Policy requires nonces on injected `<style>` elements:

```typescript
const devtools = new QueryDevtools({
  client: queryClient,
  styleNonce: document.querySelector('meta[name="csp-nonce"]')?.getAttribute('content') ?? undefined,
});
```

---

## Shadow DOM target

By default the devtools creates its own `<div>` with a shadow root attached to `document.body`. To mount inside an existing shadow root instead:

```typescript
const host = document.getElementById('devtools-host')!;
const shadow = host.attachShadow({ mode: 'open' });

const devtools = new QueryDevtools({
  client: queryClient,
  shadowDOMTarget: shadow,
});
```

## Framework integration examples

### Vanilla

```typescript
import { QueryClient, QueryCache } from '@headless-form/query-core';
import { QueryDevtools } from '@headless-form/query-devtools';

const queryClient = new QueryClient({
  queryCache: new QueryCache(),
});

queryClient.mount();

if (import.meta.env.DEV) {
  const devtools = new QueryDevtools({
    client: queryClient,
    initialIsOpen: false,
  });

  // Cleanup on HMR
  if (import.meta.hot) {
    import.meta.hot.dispose(() => devtools.destroy());
  }
}
```

### React

```tsx
import { useEffect, useRef } from 'react';
import { QueryDevtools } from '@headless-form/query-devtools';
import { useQueryClient } from './hooks'; // your typed hook

export function DevtoolsProvider() {
  const queryClient = useQueryClient();
  const devtoolsRef = useRef<QueryDevtools | null>(null);

  useEffect(() => {
    if (process.env.NODE_ENV !== 'production') {
      devtoolsRef.current = new QueryDevtools({
        client: queryClient,
        initialIsOpen: false,
        buttonPosition: 'bottom-right',
      });
    }
    return () => {
      devtoolsRef.current?.destroy();
    };
  }, [queryClient]);

  return null; // devtools renders itself into document.body
}
```

### Angular

```typescript
import { Injectable, OnDestroy } from '@angular/core';
import { QueryDevtools } from '@headless-form/query-devtools';
import { QueryClientService } from './query-client.service';

@Injectable({ providedIn: 'root' })
export class DevtoolsService implements OnDestroy {
  private devtools?: QueryDevtools;

  constructor(queryClientService: QueryClientService) {
    if (!isDevMode()) return;
    this.devtools = new QueryDevtools({
      client: queryClientService.client,
      initialIsOpen: false,
    });
  }

  ngOnDestroy() {
    this.devtools?.destroy();
  }
}
```

## What the panel shows

| Panel | Description |
|-------|-------------|
| Query list | All queries in the cache, sorted by key. Shows status badge, observer count, stale indicator. |
| Query detail | Selected query's full state: data (pretty-printed JSON), error, timing, actions. |
| Actions | Trigger refetch, invalidate, remove, or reset for the selected query. |
| Error picker | Inject a custom error into a query for testing error states. |
| Explorer | Nested JSON tree explorer for query data. |

Status badges:

| Badge | Meaning |
|-------|---------|
| `fetching` | Query is currently in-flight |
| `paused` | Paused waiting for network |
| `stale` | Data is older than `staleTime` |
| `inactive` | No observers are watching |
| `fresh` | Data is within `staleTime` and has active observers |
