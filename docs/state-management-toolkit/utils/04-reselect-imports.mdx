# reselectImports

**File:** `src/reselectImports.ts` · Internal, not exported from the package root.

```typescript
export { createSelectorCreator, weakMapMemoize } from 'reselect'
```

The smallest of the three dependency-isolation barrels (alongside [reduxImports](./02-redux-imports) and [immerImports](./03-immer-imports)) — re-exports exactly the two pieces of [reselect](https://github.com/reduxjs/reselect) that [createDraftSafeSelector](../03-create-draft-safe-selector) builds on:

| Re-export | Used for |
|-----------|----------|
| `createSelectorCreator` | Builds a custom-memoization-strategy version of `createSelector` — `createDraftSafeSelector` is exactly `createSelectorCreator(weakMapMemoize)` wrapped with draft-detection. |
| `weakMapMemoize` | `reselect`'s `WeakMap`-based memoization strategy — chosen as the default for `createDraftSafeSelector` because it scales well across selectors instantiated repeatedly with different (but structurally similar) input combinations, without manual cache-size tuning. |

## Basic usage (you won't import this directly)

Application code that needs `reselect`'s own exports directly (`createSelector`, other memoize strategies, etc.) should depend on and import from `reselect` itself; this file exists purely to centralize the toolkit's own internal dependency on those two specific exports.

- **None specific to application code** — purely an internal re-export.
