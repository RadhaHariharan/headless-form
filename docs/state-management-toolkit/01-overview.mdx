# State Management Toolkit

`@headlesskit/state-management-toolkit` is an opinionated state-management toolset. It re-exports everything from `@headlesskit/state-management` and adds `configureStore`, `createSlice`, `createAsyncThunk`, `createEntityAdapter`, the listener middleware, a data-fetching/caching layer, and more.

```bash
pnpm add @headlesskit/state-management-toolkit
# or
npm install @headlesskit/state-management-toolkit
```

> `@headlesskit/state-management` is a peer dependency resolved automatically within the monorepo. You do not need to install it separately.

---

## configureStore

The recommended way to create a store. Automatically wires up:
- thunk middleware (built in, no extra dependency)
- Dev-mode invariant checks (immutable state, serializable state, action creator dispatch)
- headlesskit's DevTools connector (`window.__HEADLESSKIT_DEVTOOLS_EXTENSION__`)

```typescript
import { configureStore } from '@headlesskit/state-management-toolkit';

const store = configureStore({
  reducer: rootReducer,
});
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `reducer` | `Reducer \| { [key: string]: Reducer }` | — | Root reducer or slice map |
| `middleware` | `Middleware[] \| (getDefault) => Middleware[]` | `getDefaultMiddleware()` | Middleware array or factory |
| `devTools` | `boolean \| DevToolsEnhancerOptions` | `true` | Enable/configure DevTools |
| `preloadedState` | `Partial<State>` | — | Initial state for hydration |
| `enhancers` | `StoreEnhancer[] \| (getDefault) => StoreEnhancer[]` | `[applyMiddleware(...middleware)]` | Additional store enhancers |

```typescript
import { configureStore } from '@headlesskit/state-management-toolkit';
import { counterSlice } from './counterSlice';
import { todosSlice } from './todosSlice';

const store = configureStore({
  reducer: {
    counter: counterSlice.reducer,
    todos: todosSlice.reducer,
  },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware({
      serializableCheck: { ignoredActions: ['SOME_ACTION'] },
    }),
  devTools: process.env.NODE_ENV !== 'production',
});

export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;
```

## createSlice

Generates a reducer and action creators from a single configuration object. The recommended pattern for writing action/reducer logic.

```typescript
import { createSlice } from '@headlesskit/state-management-toolkit';
import type { PayloadAction } from '@headlesskit/state-management-toolkit';

interface CounterState {
  value: number;
  status: 'idle' | 'loading' | 'failed';
}

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0, status: 'idle' } as CounterState,
  reducers: {
    increment(state) {
      state.value += 1;
    },
    decrement(state) {
      state.value -= 1;
    },
    incrementByAmount(state, action: PayloadAction<number>) {
      state.value += action.payload;
    },
    reset(state) {
      state.value = 0;
    },
  },
});

export const { increment, decrement, incrementByAmount, reset } = counterSlice.actions;
export default counterSlice.reducer;
```

Reducers in `createSlice` use **Immer** — you can write mutating code and it produces an immutable result.

### Options

| Option | Type | Description |
|--------|------|-------------|
| `name` | `string` | Prefix for all generated action type strings |
| `initialState` | `State \| () => State` | Initial state value or factory function |
| `reducers` | `{ [key]: CaseReducer \| { reducer, prepare } }` | Map of case reducers |
| `extraReducers` | `(builder) => void` | Handle actions from other slices or `createAsyncThunk` |
| `reducerPath` | `string` | Override the default reducer key (defaults to `name`) |
| `selectors` | `{ [key]: (state) => value }` | Memoized selectors scoped to slice state |

### Slice return value

| Property | Type | Description |
|----------|------|-------------|
| `name` | `string` | The slice name |
| `reducer` | `Reducer` | The generated reducer function |
| `actions` | `CaseReducerActions` | Generated action creators |
| `caseReducers` | `object` | The raw case reducer functions |
| `getInitialState()` | `() => State` | Returns the initial state |
| `selectSlice` | `(rootState) => State` | Selects this slice from root state |
| `injectInto(injectable)` | — | Lazy injection via `combineSlices` |

### Prepare callbacks

Use a `{ prepare, reducer }` object to customize the action payload:

```typescript
const todosSlice = createSlice({
  name: 'todos',
  initialState: [] as { id: string; text: string; done: boolean }[],
  reducers: {
    addTodo: {
      prepare(text: string) {
        return { payload: { id: nanoid(), text, done: false } };
      },
      reducer(state, action: PayloadAction<{ id: string; text: string; done: boolean }>) {
        state.push(action.payload);
      },
    },
  },
});
```

### extraReducers — handling async thunks

```typescript
const postsSlice = createSlice({
  name: 'posts',
  initialState: { items: [] as Post[], loading: false, error: null as string | null },
  reducers: {},
  extraReducers: (builder) => {
    builder
      .addCase(fetchPosts.pending, (state) => {
        state.loading = true;
        state.error = null;
      })
      .addCase(fetchPosts.fulfilled, (state, action) => {
        state.loading = false;
        state.items = action.payload;
      })
      .addCase(fetchPosts.rejected, (state, action) => {
        state.loading = false;
        state.error = action.error.message ?? 'Failed';
      });
  },
});
```

### Selectors

```typescript
const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: { increment: (state) => { state.value += 1 } },
  selectors: {
    selectValue: (state) => state.value,
    selectDoubled: (state) => state.value * 2,
  },
});

const { selectValue, selectDoubled } = counterSlice.selectors;
// selectValue(rootState) — picks counterSlice.value from rootState
```

## createAction

Creates a typed action creator.

```typescript
import { createAction } from '@headlesskit/state-management-toolkit';

const increment = createAction('counter/increment');
const addAmount = createAction<number>('counter/add');

increment();          // { type: 'counter/increment' }
addAmount(5);         // { type: 'counter/add', payload: 5 }

// Type guard
increment.match({ type: 'counter/increment' }); // true
```

With a prepare callback:

```typescript
const addTodo = createAction('todos/add', (text: string) => ({
  payload: { id: nanoid(), text, createdAt: Date.now() },
}));

addTodo('Buy groceries');
// { type: 'todos/add', payload: { id: '...', text: 'Buy groceries', createdAt: 1234567890 } }
```

### isActionCreator / isFluxStandardAction

```typescript
import { isActionCreator, isFluxStandardAction } from '@headlesskit/state-management-toolkit';

isActionCreator(increment);          // true — has .type and is callable
isActionCreator(() => {});           // false — no .type property

isFluxStandardAction({ type: 'x', payload: 1 });               // true
isFluxStandardAction({ type: 'x', payload: 1, meta: {} });      // true
isFluxStandardAction({ type: 'x', extra: 1 });                  // false — unknown key outside the FSA shape
```

## createReducer

Creates a type-safe reducer using a builder API. Uses Immer internally.

```typescript
import { createReducer } from '@headlesskit/state-management-toolkit';

const counterReducer = createReducer({ value: 0 }, (builder) => {
  builder
    .addCase('counter/increment', (state) => { state.value += 1 })
    .addCase('counter/decrement', (state) => { state.value -= 1 })
    .addCase(addAmount, (state, action) => { state.value += action.payload })
    .addMatcher(
      (action) => action.type.endsWith('/reset'),
      (state) => { state.value = 0 }
    )
    .addDefaultCase((state, action) => {
      // handle any unmatched action
    });
});
```

### Builder methods

| Method | Description |
|--------|-------------|
| `addCase(type \| actionCreator, reducer)` | Handle a specific action type. Must be called before `addMatcher`. |
| `addMatcher(predicate, reducer)` | Handle any action matching a predicate. Can chain multiple. |
| `addDefaultCase(reducer)` | Fallback when no case or matcher matches. |

## createAsyncThunk

Creates a thunk action that dispatches `pending`, `fulfilled`, and `rejected` actions around an async operation.

```typescript
import { createAsyncThunk } from '@headlesskit/state-management-toolkit';

interface Post { id: number; title: string }

const fetchPost = createAsyncThunk(
  'posts/fetch',
  async (postId: number, { signal }) => {
    const response = await fetch(`/api/posts/${postId}`, { signal });
    if (!response.ok) throw new Error('Failed to fetch');
    return (await response.json()) as Post;
  }
);

// Dispatching
store.dispatch(fetchPost(42));

// Lifecycle actions
fetchPost.pending   // { type: 'posts/fetch/pending' }
fetchPost.fulfilled // { type: 'posts/fetch/fulfilled', payload: Post }
fetchPost.rejected  // { type: 'posts/fetch/rejected', error: SerializedError }
```

### ThunkAPI

The second argument to the payload creator provides these utilities:

| Property | Type | Description |
|----------|------|-------------|
| `dispatch` | `AppDispatch` | Store dispatch |
| `getState` | `() => RootState` | Current state snapshot |
| `extra` | `unknown` | Extra argument from thunk middleware |
| `requestId` | `string` | Unique ID for this invocation |
| `signal` | `AbortSignal` | Abort signal for cancellation |
| `rejectWithValue(value)` | — | Reject with a custom payload (not an error) |
| `fulfillWithValue(value, meta?)` | — | Fulfill with additional meta |

### Typed thunk API

```typescript
const fetchUser = createAsyncThunk<
  User,           // return type
  number,         // argument type
  {
    state: RootState;
    rejectValue: { message: string };
  }
>('users/fetch', async (userId, { getState, rejectWithValue, signal }) => {
  const token = getState().auth.token;
  const response = await fetch(`/api/users/${userId}`, {
    headers: { Authorization: `Bearer ${token}` },
    signal,
  });
  if (!response.ok) {
    return rejectWithValue({ message: await response.text() });
  }
  return response.json();
});
```

### Cancellation

```typescript
const promise = store.dispatch(fetchUser(1));

// Abort mid-flight
promise.abort('User navigated away');

// In the thunk, check signal
async (userId, { signal }) => {
  const response = await fetch(`/api/users/${userId}`, { signal });
  // If aborted, fetch throws and the rejected action is dispatched
};
```

### unwrapResult

Extracts the fulfilled payload or re-throws the rejection:

```typescript
import { unwrapResult } from '@headlesskit/state-management-toolkit';

try {
  const user = unwrapResult(await store.dispatch(fetchUser(1)));
  console.log(user); // User
} catch (error) {
  console.error(error); // custom rejectValue or SerializedError
}
```

### miniSerializeError

Converts a thrown value into a plain, serializable `SerializedError` (`{ name, message, stack, code }`). Used internally to build the `rejected` action's `error` field; useful when you need the same normalization elsewhere.

```typescript
import { miniSerializeError } from '@headlesskit/state-management-toolkit';

try {
  JSON.parse('not json');
} catch (err) {
  const serialized = miniSerializeError(err);
  // { name: 'SyntaxError', message: '...', stack: '...' }
}
```

### Condition / abort before dispatch

```typescript
const fetchUser = createAsyncThunk(
  'users/fetch',
  async (userId: number) => { /* ... */ },
  {
    condition(userId, { getState }) {
      // Return false to skip dispatching entirely
      const existing = getState().users.entities[userId];
      return !existing;
    },
    dispatchConditionRejection: true, // dispatch rejected action even when condition is false
  }
);
```

## createEntityAdapter

Provides pre-built CRUD reducer logic and selectors for normalized entity collections.

```typescript
import { createEntityAdapter } from '@headlesskit/state-management-toolkit';

interface Post {
  id: number;
  title: string;
  author: string;
}

const postsAdapter = createEntityAdapter<Post>();
// Infers id from entity.id automatically.

// Or specify a custom id selector:
const usersAdapter = createEntityAdapter<User, string>({
  selectId: (user) => user.email,
  sortComparer: (a, b) => a.name.localeCompare(b.name),
});
```

### Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `selectId` | `(entity) => EntityId` | `entity => entity.id` | Extracts the unique ID from an entity |
| `sortComparer` | `false \| (a, b) => number` | `false` | If provided, `ids` array stays sorted by this comparator |

### getInitialState

```typescript
const initialState = postsAdapter.getInitialState();
// { ids: [], entities: {} }

// With extra state fields
const initialState = postsAdapter.getInitialState({ loading: false, error: null });
// { ids: [], entities: {}, loading: false, error: null }
```

### CRUD operations

All methods accept the state as the first argument and either a value or a `PayloadAction` containing the value.

| Method | Arguments | Description |
|--------|-----------|-------------|
| `addOne` | `entity: T` | Add one entity; skips if ID already exists |
| `addMany` | `entities: T[] \| Record<Id, T>` | Add multiple entities; skips existing IDs |
| `setOne` | `entity: T` | Upsert — add or fully replace one entity |
| `setMany` | `entities: T[] \| Record<Id, T>` | Upsert multiple entities |
| `setAll` | `entities: T[] \| Record<Id, T>` | Replace entire collection |
| `updateOne` | `{ id, changes: Partial<T> }` | Partially update one entity |
| `updateMany` | `Array<{ id, changes }>` | Partially update multiple entities |
| `upsertOne` | `entity: T` | Add if not present, deep-merge if present |
| `upsertMany` | `entities: T[] \| Record<Id, T>` | Upsert multiple entities |
| `removeOne` | `id: EntityId` | Remove one entity by ID |
| `removeMany` | `ids: EntityId[]` | Remove multiple entities by ID |
| `removeAll` | — | Clear the collection |

```typescript
const postsSlice = createSlice({
  name: 'posts',
  initialState: postsAdapter.getInitialState({ status: 'idle' as 'idle' | 'loading' }),
  reducers: {
    postAdded: postsAdapter.addOne,
    postsReceived(state, action: PayloadAction<Post[]>) {
      postsAdapter.setAll(state, action.payload);
    },
    postUpdated: postsAdapter.updateOne,
    postDeleted: postsAdapter.removeOne,
  },
  extraReducers: (builder) => {
    builder
      .addCase(fetchPosts.pending, (state) => { state.status = 'loading' })
      .addCase(fetchPosts.fulfilled, (state, action) => {
        state.status = 'idle';
        postsAdapter.setAll(state, action.payload);
      });
  },
});
```

### getSelectors

Generates memoized selectors for the entity collection.

```typescript
// Without selectState — selectors operate on EntityState directly
const selectors = postsAdapter.getSelectors();
selectors.selectAll(state.posts);     // Post[]
selectors.selectById(state.posts, 1); // Post | undefined
selectors.selectIds(state.posts);     // EntityId[]
selectors.selectTotal(state.posts);   // number

// With selectState — selectors operate on root state
const selectors = postsAdapter.getSelectors((state: RootState) => state.posts);
selectors.selectAll(rootState);       // Post[]
selectors.selectById(rootState, 1);   // Post | undefined
```

| Selector | Returns | Description |
|----------|---------|-------------|
| `selectIds` | `EntityId[]` | Ordered array of entity IDs |
| `selectEntities` | `Record<Id, T>` | Dictionary of all entities |
| `selectAll` | `T[]` | All entities as an array |
| `selectTotal` | `number` | Count of entities |
| `selectById` | `T \| undefined` | Entity by ID |

## createDraftSafeSelector

Like the package's own `createSelector`, but safe to call inside Immer's `createNextState` (i.e. inside `createReducer` / `createSlice` reducers). It detects Immer drafts and uses `current()` to read the current value.

```typescript
import { createDraftSafeSelector } from '@headlesskit/state-management-toolkit';

const selectPosts = (state: RootState) => state.posts;
const selectPostIds = createDraftSafeSelector(selectPosts, (posts) => posts.ids);

// Safe inside a reducer:
builder.addCase(someAction, (state) => {
  const ids = selectPostIds(state); // works even though state is a draft
});
```

## Matchers

Predicate functions for matching actions — useful in `addMatcher`, listener middleware, and tests.

### isAllOf / isAnyOf

```typescript
import { isAllOf, isAnyOf } from '@headlesskit/state-management-toolkit';

const isUserAction = isAnyOf(userLoggedIn, userLoggedOut, userUpdated);
const isReadyAndFulfilled = isAllOf(isFulfilled(fetchUser), isReady);

builder.addMatcher(isUserAction, (state, action) => {
  state.lastActivity = Date.now();
});
```

### Async thunk matchers

| Matcher | Matches |
|---------|---------|
| `isPending(thunk?)` | `*/pending` actions |
| `isFulfilled(thunk?)` | `*/fulfilled` actions |
| `isRejected(thunk?)` | `*/rejected` actions |
| `isRejectedWithValue(thunk?)` | rejected with a custom payload (`rejectWithValue`) |
| `isAsyncThunkAction(thunk?)` | any lifecycle action from a thunk |

```typescript
import { isPending, isFulfilled, isRejected } from '@headlesskit/state-management-toolkit';

// In extraReducers
builder.addMatcher(isPending, (state) => { state.loading = true });
builder.addMatcher(isFulfilled, (state) => { state.loading = false });
builder.addMatcher(isRejected, (state, action) => {
  state.loading = false;
  state.error = action.error.message ?? null;
});

// Narrowed to specific thunks
builder.addMatcher(isPending(fetchUser, fetchPosts), (state) => {
  state.globalLoading = true;
});
```

## createListenerMiddleware

Middleware that lets you register "listeners" — side-effect handlers that react to dispatched actions, with async support, `take`, `fork`, and cancellation.

```typescript
import { createListenerMiddleware } from '@headlesskit/state-management-toolkit';

const listenerMiddleware = createListenerMiddleware();

const store = configureStore({
  reducer: rootReducer,
  middleware: (getDefault) =>
    getDefault().prepend(listenerMiddleware.middleware),
});
```

### startListening

```typescript
listenerMiddleware.startListening({
  actionCreator: increment,
  effect: async (action, listenerApi) => {
    console.log('Counter incremented to', listenerApi.getState().counter.value);
  },
});

// By type string
listenerMiddleware.startListening({
  type: 'counter/increment',
  effect: async (action, listenerApi) => { /* ... */ },
});

// By matcher
listenerMiddleware.startListening({
  matcher: isAnyOf(increment, decrement),
  effect: async (action, listenerApi) => { /* ... */ },
});

// By predicate
listenerMiddleware.startListening({
  predicate: (action, currentState, previousState) =>
    currentState.counter.value !== previousState.counter.value,
  effect: async (action, listenerApi) => { /* ... */ },
});
```

### Listener Effect API

| Method/Property | Description |
|----------------|-------------|
| `dispatch` | Store dispatch |
| `getState()` | Current state |
| `getOriginalState()` | State before the action was processed |
| `condition(predicate, timeout?)` | Wait until predicate returns `true` |
| `take(predicate, timeout?)` | Wait for the next matching action |
| `fork(executor)` | Spawn a child task |
| `delay(ms)` | Async sleep |
| `pause(promise)` | Await a promise; throws if listener is cancelled |
| `cancel()` | Cancel this listener invocation |
| `throwIfCancelled()` | Throw `TaskAbortError` if cancelled |
| `cancelActiveListeners()` | Cancel other concurrently-running instances |
| `unsubscribe()` | Remove this listener entirely |
| `signal` | `AbortSignal` tied to listener lifecycle |
| `id` | Unique listener ID |

```typescript
// Wait for a condition then perform work
listenerMiddleware.startListening({
  actionCreator: startPolling,
  effect: async (action, { condition, dispatch, getState, delay, cancel }) => {
    // Poll every 5 seconds until stopPolling is dispatched
    while (true) {
      await delay(5000);
      const stopped = await condition(stopPolling.match, 0);
      if (stopped) break;
      dispatch(fetchData());
    }
  },
});

// One-shot: cancel other running instances, run once
listenerMiddleware.startListening({
  actionCreator: searchChanged,
  effect: async (action, listenerApi) => {
    listenerApi.cancelActiveListeners();
    await listenerApi.delay(300); // debounce
    listenerApi.dispatch(fetchResults(action.payload));
  },
});
```

### Typed listeners

```typescript
import type { TypedStartListening, TypedAddListener } from '@headlesskit/state-management-toolkit';

type AppStartListening = TypedStartListening<RootState, AppDispatch>;
const startAppListening = listenerMiddleware.startListening as AppStartListening;

startAppListening({
  actionCreator: fetchUser.fulfilled,
  effect: (action, { getState }) => {
    // action and getState are fully typed
    const user = action.payload; // User
  },
});
```

### Adding/removing listeners by dispatch

`addListener`, `removeListener`, and `clearAllListeners` are action creators — an alternative to calling `listenerMiddleware.startListening()` directly, useful when you want to manage listeners from inside a thunk or another reducer.

```typescript
import { addListener, removeListener, clearAllListeners } from '@headlesskit/state-management-toolkit';

store.dispatch(
  addListener({
    actionCreator: increment,
    effect: async (action, listenerApi) => { /* ... */ },
  })
);

store.dispatch(removeListener({ actionCreator: increment, effect: someEffect }));
store.dispatch(clearAllListeners());
```

### TaskAbortError

Thrown inside a listener effect when its task is cancelled (e.g. via `cancelActiveListeners()` or `cancel()`). Check for it if you wrap awaited work in `try/catch`.

```typescript
import { TaskAbortError } from '@headlesskit/state-management-toolkit';

listenerMiddleware.startListening({
  actionCreator: searchChanged,
  effect: async (action, { delay, dispatch }) => {
    try {
      await delay(300);
      dispatch(fetchResults(action.payload));
    } catch (err) {
      if (err instanceof TaskAbortError) return; // cancelled by a newer keystroke
      throw err;
    }
  },
});
```

## createDynamicMiddleware

Allows adding middleware to the store at runtime after it has been created.

```typescript
import { createDynamicMiddleware } from '@headlesskit/state-management-toolkit';

const dynamicMiddleware = createDynamicMiddleware();

const store = configureStore({
  reducer: rootReducer,

    getDefault().prepend(dynamicMiddleware.middleware),

// Add middleware later (e.g. after a feature loads)

// Or dispatch a special action
store.dispatch(dynamicMiddleware.withMiddleware(analyticsMiddleware));
```

## autoBatchEnhancer

Batches multiple state updates within one RAF/tick into a single subscriber notification. Useful for high-frequency updates.

```typescript
import { autoBatchEnhancer, prepareAutoBatched } from '@headlesskit/state-management-toolkit';

const store = configureStore({
  reducer: rootReducer,
  enhancers: (getDefault) => getDefault().concat(autoBatchEnhancer()),
});

// Mark an action as "should be auto-batched"
const updatePosition = createAction('canvas/updatePosition', prepareAutoBatched<Position>());
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `type` | `'raf' \| 'tick' \| 'timer' \| 'callback'` | `'raf'` | Batching strategy |
| `timeout` | `number` | `0` | Delay in ms when `type: 'timer'` |

## combineSlices

Lazily assembles slices into a root reducer. Supports injecting new slices at runtime without recreating the store.

```typescript
import { combineSlices } from '@headlesskit/state-management-toolkit';

// Static slices
const rootReducer = combineSlices(counterSlice, authSlice);

// Lazy injection (e.g. after code-split load)
const injectedReducer = rootReducer.inject(postsSlice);

// With type information for lazy slices
const lazyRootReducer = rootReducer.withLazyLoadedSlices<
  WithSlice<typeof postsSlice>
>();

// Scoped selector
const selectPosts = rootReducer.selector(
  (state) => state.posts,
  (rootState: RootState) => rootState
);
```

## Immer re-exports

`@headlesskit/state-management-toolkit` re-exports a few Immer helpers directly, since `createReducer`/`createSlice` reducers operate on Immer drafts.

```typescript
import { current, isDraft, createNextState, original, freeze } from '@headlesskit/state-management-toolkit';
import type { Draft, WritableDraft } from '@headlesskit/state-management-toolkit';
```

| Export | Description |
|--------|-------------|
| `current(draft)` | Returns a plain snapshot of the current draft state, useful for logging mid-reducer |
| `isDraft(value)` | `true` if the value is an Immer draft |
| `createNextState(base, recipe)` | Immer's `produce`, re-exported under this package's internal name |
| `original(draft)` | Returns the pre-mutation value a draft was created from |
| `freeze(value)` | Deeply freezes a plain object/array |
| `Draft<T>` / `WritableDraft<T>` | Type of a value as seen inside a draft recipe |

```typescript
builder.addCase(someAction, (state) => {
  console.log('before mutation:', current(state));
  state.value += 1;
});
```

> The full implementation behind these re-exports is vendored directly into this package — see [the selector module docs](./reselect/01-overview) for how `createSelector`, the memoization strategies, `createStructuredSelector`, and the development-only stability checks actually work.

```typescript
import { createSelector, createSelectorCreator, lruMemoize, weakMapMemoize } from '@headlesskit/state-management-toolkit';
```

## buildCreateSlice / asyncThunkCreator

`createSlice` is itself built by calling `buildCreateSlice()` with no arguments. Pass `asyncThunkCreator` to get a `create.asyncThunk(...)` reducer creator inside the `reducers` builder callback form.

```typescript
import { buildCreateSlice, asyncThunkCreator } from '@headlesskit/state-management-toolkit';

const createAppSlice = buildCreateSlice({
  creators: { asyncThunk: asyncThunkCreator },
});

const postsSlice = createAppSlice({
  name: 'posts',
  initialState: { items: [] as Post[], loading: false },
  reducers: (create) => ({
    fetchPosts: create.asyncThunk(
      async () => {
        const res = await fetch('/api/posts');
        return (await res.json()) as Post[];
      },
      {
        pending: (state) => { state.loading = true },
        fulfilled: (state, action) => { state.items = action.payload; state.loading = false },
        rejected: (state) => { state.loading = false },
      },
    ),
  }),
});
```

`ReducerType` is the internal enum (`reducer`, `reducerWithPrepare`, `asyncThunk`) used to tag entries produced by the `reducers` builder callback — most code never needs to reference it directly.

## Dev-mode Middleware

`getDefaultMiddleware` includes these three in development only (removed in production builds):

### actionCreatorInvariantMiddleware

Warns when you dispatch an action creator function instead of calling it first.

```typescript
// ❌ Wrong — dispatches the function itself
store.dispatch(increment);

// ✅ Correct
store.dispatch(increment());
```

### immutableStateInvariantMiddleware

Detects mutations to state between dispatches and throws an error.

```typescript
// ❌ This mutation would be caught in dev mode
store.getState().counter.value = 99;
store.dispatch(anotherAction()); // throws
```

### serializableStateInvariantMiddleware

Warns when non-serializable values (functions, Promises, class instances, etc.) appear in state or actions.

```typescript
// Disable checks for specific paths
const store = configureStore({
  reducer: rootReducer,
  middleware: (getDefault) =>
    getDefault({
      serializableCheck: {
        ignoredActions: ['mySlice/setCallback'],
        ignoredPaths: ['mySlice.callback'],
      },
    }),
});
```

## TypeScript Setup

### Typed hooks pattern

This package ships no React bindings of its own — `configureStore` returns a plain store, so wire it up with `useSyncExternalStore`:

```typescript
// store.ts
export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;

// hooks.ts
import { useSyncExternalStore } from 'react';
import { store } from './store';
import type { RootState, AppDispatch } from './store';

export const useAppDispatch = (): AppDispatch => store.dispatch;
export const useAppSelector = <T>(selector: (state: RootState) => T): T =>
  useSyncExternalStore(
    store.subscribe,
    () => selector(store.getState()),
    () => selector(store.getState()),
  );
```

### Typed createAsyncThunk

```typescript
import { createAsyncThunk } from '@headlesskit/state-management-toolkit';
import type { RootState, AppDispatch } from './store';

export const createAppThunk = createAsyncThunk.withTypes<{
  state: RootState;
  dispatch: AppDispatch;
  rejectValue: string;
}>();

const fetchUser = createAppThunk('users/fetch', async (userId: number, { rejectWithValue }) => {
  const res = await fetch(`/api/users/${userId}`);
  if (!res.ok) return rejectWithValue('Server error');
  return res.json() as Promise<User>;
});
```
