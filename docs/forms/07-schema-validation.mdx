# Schema Validation

`headlesskit` supports [Standard Schema](https://standardschema.dev/) — a community
specification implemented by many popular validation libraries. Use `schemaResolver` to
validate forms with any Standard Schema-compliant library without extra adapter packages.

Supported libraries include:
- [Zod](https://zod.dev) (v4+)
- [Valibot](https://valibot.dev)
- [Arktype](https://arktype.io)
- [And many more](https://standardschema.dev/schema#what-schema-libraries-implement-the-spec)

---

## Installation

Install `@headlesskit/forms-react` (or `/core`) alongside your preferred schema library:

```bash
# Zod
npm install @headlesskit/forms-react zod

# Valibot
npm install @headlesskit/forms-react valibot

# Arktype
npm install @headlesskit/forms-react arktype
```

---

## Basic Usage

Import `schemaResolver` and pass it to the `validate` option:

```typescript
import { schemaResolver } from '@headlesskit/forms-react';
// or
import { schemaResolver } from '@headlesskit/forms';
```

---

## Sync vs Async Schemas

By default, `schemaResolver` returns a resolver that may return a `Promise` because the Standard
Schema spec allows async validation. Pass `{ sync: true }` when you know your schema is
synchronous (e.g., Zod without async refinements, Valibot) to get synchronous return types
for `form.validate()`, `form.validateField()`, and `form.isValid()`:

```typescript
// Async (default) — form.validate() returns Promise<FormValidateResult>
validate: schemaResolver(schema)

// Sync — form.validate() returns FormValidateResult directly
validate: schemaResolver(schema, { sync: true })
```

### Basic Field Validation

```tsx
import { z } from 'zod/v4';
import { useForm } from '@headlesskit/forms-react';
import { schemaResolver } from '@headlesskit/forms-react';

const schema = z.object({
  name: z.string().min(2, { error: 'Name must have at least 2 letters' }),
  email: z.email({ error: 'Invalid email' }),
  age: z.number().min(18, { error: 'You must be at least 18' }),
});

function Demo() {
  const form = useForm({
    mode: 'uncontrolled',
    initialValues: {
      name: '',
      email: '',
      age: 16,
    },
    validate: schemaResolver(schema, { sync: true }),
  });

  return (
    <form onSubmit={form.onSubmit(console.log)}>
      <input key={form.key('name')} {...form.getInputProps('name')} placeholder="Name" />
      {form.errors.name && <p>{form.errors.name}</p>}

      <input key={form.key('email')} {...form.getInputProps('email')} placeholder="Email" />
      {form.errors.email && <p>{form.errors.email}</p>}

      <input key={form.key('age')} {...form.getInputProps('age')} type="number" />
      {form.errors.age && <p>{form.errors.age}</p>}

      <button type="submit">Submit</button>
    </form>
  );
}
```

After calling `form.validate()`:
```typescript
form.errors;
// -> {
//   name: 'Name must have at least 2 letters',
//   email: 'Invalid email',
//   age: 'You must be at least 18',
// }
```

### Nested Object Validation

```tsx
import { z } from 'zod/v4';
import { useForm, schemaResolver } from '@headlesskit/forms-react';

const schema = z.object({
  user: z.object({
    name: z.string().min(2, { error: 'Name must have at least 2 letters' }),
    email: z.email({ error: 'Invalid email' }),
  }),
});

const form = useForm({
  mode: 'uncontrolled',
  initialValues: {
    user: { name: '', email: '' },
  },
  validate: schemaResolver(schema, { sync: true }),
});

await form.validate();
form.errors;
// -> {
//   'user.name': 'Name must have at least 2 letters',
//   'user.email': 'Invalid email',
// }
```

### List Field Validation

```tsx
import { z } from 'zod/v4';
import { useForm, schemaResolver } from '@headlesskit/forms-react';

const schema = z.object({
  users: z.array(
    z.object({
      name: z.string().min(2, { error: 'Name must have at least 2 letters' }),
      email: z.email({ error: 'Invalid email' }),
    })
  ),
});

const form = useForm({
  mode: 'uncontrolled',
  initialValues: {
    users: [{ name: '', email: '' }],
  },
  validate: schemaResolver(schema, { sync: true }),
});

await form.validate();
form.errors;
// -> {
//   'users.0.name': 'Name must have at least 2 letters',
//   'users.0.email': 'Invalid email',
// }
```

### Async Schema Validation

When your schema includes async refinements (e.g., checking if an email is already taken),
use `schemaResolver` without `{ sync: true }`. `form.validate()` and `form.onSubmit()` will
handle promises automatically:

```tsx
import { z } from 'zod/v4';
import { useForm, schemaResolver } from '@headlesskit/forms-react';

const schema = z
  .object({
    email: z.email({ error: 'Invalid email' }),
  })
  .refine(
    async (data) => {
      const taken = await checkEmailExists(data.email);
      return !taken;
    },
    { error: 'Email is already taken', path: ['email'] }
  );

function Demo() {
  const form = useForm({
    mode: 'uncontrolled',
    initialValues: { email: '' },
    // No { sync: true } — this schema is async
    validate: schemaResolver(schema),
  });

  return (
    <form onSubmit={form.onSubmit(console.log)}>
      <input key={form.key('email')} {...form.getInputProps('email')} type="email" />
      {form.validating && <span>Checking email…</span>}
      {form.errors.email && <p>{form.errors.email}</p>}
      <button type="submit" disabled={form.submitting}>Submit</button>
    </form>
  );
}
```

import * as v from 'valibot';
import { useForm, schemaResolver } from '@headlesskit/forms-react';

const schema = v.object({
  name: v.pipe(

  email: v.pipe(
    v.string(),

      <input key={form.key('email')} {...form.getInputProps('email')} placeholder="Email" />

}

## Schema Resolver API

```typescript
import { schemaResolver } from '@headlesskit/forms-react';
import type { SchemaResolverOptions, StandardSchema } from '@headlesskit/forms-react';

// Usage
const resolver = schemaResolver(schema, options);

// Options
interface SchemaResolverOptions {
  // Pass { sync: true } when you know your schema is synchronous.
  // This makes form.validate() / form.validateField() / form.isValid()
  // return results directly (not wrapped in a Promise).
  sync?: boolean;
}
```

The `schemaResolver` function returns a function that can be passed to the `validate` option
of `useForm` / `injectForm` / `createFormStore`. It handles:
- Flattening nested schema errors to dot-notation keys
- Mapping Standard Schema issues to the form's error format
- Sync and async validation

## Vanilla / Core

```typescript
import { createFormStore, schemaResolver } from '@headlesskit/forms';
import { z } from 'zod/v4';

const schema = z.object({
  email: z.email({ error: 'Invalid email' }),
});

const form = createFormStore({
  mode: 'uncontrolled',
  initialValues: { email: '' },
  validate: schemaResolver(schema, { sync: true }),
});

// Validate synchronously
const result = form.validate();
// result: { hasErrors: boolean, errors: { email?: string } }
```
