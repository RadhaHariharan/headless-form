# Getting Started

`headlesskit` is a framework-agnostic form state engine with zero runtime dependencies
and first-class React (web and native) wrappers.

| Package | Description |
|---------|-------------|
| `@headlesskit/forms` | Pure TypeScript form engine — zero deps |
| `@headlesskit/forms-react` | React 18 bindings via `useSyncExternalStore` |
| `@headlesskit/forms-react-native` | React Native prop adapters built on top of `forms-react` |

---

## Installation

### React (web)

```bash
npm install @headlesskit/forms-react
# or
pnpm add @headlesskit/forms-react
# or
yarn add @headlesskit/forms-react
```

### React Native

```bash
npm install @headlesskit/forms-react-native
```

### Vanilla / Core only

```bash
npm install @headlesskit/forms
```

## Basic Usage

### React

```tsx
import { useForm } from '@headlesskit/forms-react';
import { isEmail, isNotEmpty } from '@headlesskit/forms-react';

function ContactForm() {
  const form = useForm({
    mode: 'uncontrolled',
    initialValues: {
      name: '',
      email: '',
    },
    validate: {
      name: isNotEmpty('Name is required'),
      email: isEmail('Invalid email'),
    },
  });

  const handleSubmit = form.onSubmit((values) => {
    console.log(values);
  });

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label>Name</label>
        <input
          key={form.key('name')}
          {...form.getInputProps('name')}
          placeholder="Your name"
        />
        {form.errors.name && <span style={{ color: 'red' }}>{form.errors.name}</span>}
      </div>

      <div>
        <label>Email</label>
        <input
          key={form.key('email')}
          {...form.getInputProps('email')}
          type="email"
          placeholder="your@email.com"
        />
        {form.errors.email && <span style={{ color: 'red' }}>{form.errors.email}</span>}
      </div>

      <button type="submit">Submit</button>
    </form>
  );
}
```

### React Native

```tsx
import { useForm, getTextInputProps, getSubmitHandler } from '@headlesskit/forms-react-native';
import { isEmail, isNotEmpty } from '@headlesskit/forms-react-native';
import { View, Text, TextInput, Button } from 'react-native';

function ContactForm() {
  const form = useForm({
    mode: 'uncontrolled',
    initialValues: { name: '', email: '' },
    validate: {
      name: isNotEmpty('Name is required'),
      email: isEmail('Invalid email'),
    },
  });

  return (
    <View>
      <Text>Name</Text>
      <TextInput key={form.key('name')} {...getTextInputProps(form, 'name')} />
      {form.errors.name && <Text style={{ color: 'red' }}>{form.errors.name}</Text>}

      <Text>Email</Text>
      <TextInput key={form.key('email')} {...getTextInputProps(form, 'email')} />
      {form.errors.email && <Text style={{ color: 'red' }}>{form.errors.email}</Text>}

      <Button title="Submit" onPress={getSubmitHandler(form, (values) => console.log(values))} />
    </View>
  );
}
```

### Vanilla (Core)

```typescript
import { createFormStore, isEmail, isNotEmpty } from '@headlesskit/forms';

const form = createFormStore({
  mode: 'uncontrolled',
  initialValues: { name: '', email: '' },
  validate: {
    name: isNotEmpty('Name is required'),
    email: isEmail('Invalid email'),
  },
});

// Subscribe to state changes (errors, touched, dirty, etc.)
const unsubscribe = form.subscribe(() => {
  renderUI(form.getSnapshot());
});

// Wire up inputs manually
const nameInput = document.querySelector('#name') as HTMLInputElement;
Object.assign(nameInput, form.getInputProps('name'));

// Submit
document.querySelector('form')!.addEventListener('submit', 
  form.onSubmit((values) => console.log(values))
);
```

## Features

- **Zero dependencies** in `@headlesskit/forms`
- **Controlled and uncontrolled modes** — uncontrolled mode causes zero re-renders on typing
- **Deep path inference** — `form.getInputProps('user.address.city')` is fully typed
- **Built-in validators** — `isNotEmpty`, `isEmail`, `matches`, `matchesField`, `isInRange`, `hasLength`, `isJSONString`, `isNotEmptyHTML`
- **Standard Schema resolver** — works with Zod v4, Valibot, Arktype and any Standard Schema-compliant library
- **Async-first validation** — generation-guarded, abortable with `AbortSignal`, debounced
- **List helpers** — `insertListItem`, `removeListItem`, `replaceListItem`, `reorderListItem`
- **Named forms** — global registry + `createFormActions` for cross-component state control
- **`useField`** — a standalone single-field hook for composable forms
- **Form context** — `createFormContext` for sharing one form across a component tree
- **React Native ready** — `@headlesskit/forms-react-native` adapts `getInputProps` to `<TextInput>`/`<Switch>` conventions

## TypeScript

All packages ship full TypeScript types. The form values type is inferred from `initialValues`:

```typescript
import { useForm } from '@headlesskit/forms-react';

// Inferred from initialValues
const form = useForm({
  initialValues: {
    name: '',        // string
    age: 0,          // number
    active: false,   // boolean
  },
});

// Or provide an explicit type
interface MyFormValues {
  name: string;
  age: number;
  active: boolean;
}

const form2 = useForm<MyFormValues>({
  initialValues: {
    name: '',
    age: 0,
    active: false,
  },
});
```
