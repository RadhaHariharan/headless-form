# State Management

`@headlesskit/state-management` is a predictable state container for JavaScript apps, API-compatible with Redux v5. It is a zero-dependency, pure TypeScript package included in this monorepo so that `@headlesskit/state-management-toolkit` can resolve it internally without an external peer dependency.

| Package | Description |
|---------|-------------|
| `@headlesskit/state-management` | Redux v5-compatible — zero dependencies, full TypeScript |
| `@headlesskit/state-management-toolkit` | Redux Toolkit v2-compatible — builds on top of this package |

---

## Installation

```bash
pnpm add @headlesskit/state-management
# or
npm install @headlesskit/state-management
```

## Core Concepts

Redux manages application state with three principles:

1. **Single source of truth** — the whole app state lives in one store
2. **State is read-only** — the only way to change state is to dispatch an action
3. **Pure reducer functions** — reducers specify how state transforms in response to actions

```
Action → Reducer → New State → Subscribers notified
```

## createStore

Creates a Redux store holding the complete state tree.

```typescript
import { createStore } from '@headlesskit/state-management';

const store = createStore(reducer);
const store = createStore(reducer, preloadedState);
const store = createStore(reducer, enhancer);
const store = createStore(reducer, preloadedState, enhancer);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `reducer` | `Reducer<S, A>` | The root reducer function |
| `preloadedState` | `PreloadedState` | Optional initial state (useful for SSR hydration) |
| `enhancer` | `StoreEnhancer` | Optional store enhancer (e.g. `applyMiddleware(...)`) |

**Returns:** `Store<S, A>`

```typescript
import { createStore } from '@headlesskit/state-management';

type CounterState = { count: number };
type CounterAction =
  | { type: 'INCREMENT' }
  | { type: 'DECREMENT' }
  | { type: 'RESET' };

function counterReducer(
  state: CounterState = { count: 0 },
  action: CounterAction
): CounterState {
  switch (action.type) {
    case 'INCREMENT':
      return { count: state.count + 1 };
    case 'DECREMENT':
      return { count: state.count - 1 };
    case 'RESET':
      return { count: 0 };
    default:
      return state;
  }
}

const store = createStore(counterReducer);

store.dispatch({ type: 'INCREMENT' });
store.dispatch({ type: 'INCREMENT' });
console.log(store.getState()); // { count: 2 }
```

> `legacy_createStore` is also exported — it is identical to `createStore` but does not trigger the DevTools deprecation notice. Prefer `configureStore` from `@headlesskit/state-management-toolkit` for new apps.

## Store API

The object returned by `createStore`.

### getState

Returns the current state tree.

```typescript
store.getState(): S
```

```typescript
const { count } = store.getState();
console.log(count); // 0
```

### dispatch

Dispatches an action. Actions must be plain objects with a `type: string` field.

```typescript
store.dispatch(action: Action): Action
```

```typescript
store.dispatch({ type: 'INCREMENT' });
store.dispatch({ type: 'ADD', payload: 5 });
```

### subscribe

Adds a change listener. Called after every dispatch.

```typescript
store.subscribe(listener: () => void): Unsubscribe
```

```typescript
const unsubscribe = store.subscribe(() => {
  console.log('State changed:', store.getState());
});

store.dispatch({ type: 'INCREMENT' }); // listener fires
unsubscribe(); // stop listening
store.dispatch({ type: 'INCREMENT' }); // listener does not fire
```

### replaceReducer

Replaces the current reducer. Useful for hot-reloading and code splitting.

```typescript
store.replaceReducer(nextReducer: Reducer<S, A>): void
```

## combineReducers

Combines multiple reducer functions into one root reducer.

```typescript
import { combineReducers } from '@headlesskit/state-management';

const rootReducer = combineReducers({
  counter: counterReducer,
  todos: todosReducer,
  user: userReducer,
});

const store = createStore(rootReducer);
store.getState();
// { counter: { count: 0 }, todos: [], user: null }
```

Each sub-reducer manages its own slice. `combineReducers` calls every sub-reducer on every dispatch and assembles the results.

```typescript
type TodosState = string[];
type TodoAction = { type: 'ADD_TODO'; text: string } | { type: 'CLEAR' };

function todosReducer(state: TodosState = [], action: TodoAction): TodosState {
  switch (action.type) {
    case 'ADD_TODO':
      return [...state, action.text];
    case 'CLEAR':
      return [];
    default:
      return state;
  }
}

const rootReducer = combineReducers({ counter: counterReducer, todos: todosReducer });
```

## applyMiddleware

Composes middleware functions into a store enhancer. Middleware intercepts every dispatched action, enabling side effects like async calls, logging, and more.

```typescript
import { createStore, applyMiddleware } from '@headlesskit/state-management';

const store = createStore(rootReducer, applyMiddleware(thunk, logger));
```

### Writing middleware

A middleware is a curried function of the shape `store => next => action => result`.

```typescript
import type { Middleware } from '@headlesskit/state-management';

const loggerMiddleware: Middleware = store => next => action => {
  console.log('Dispatching:', action);
  const result = next(action);
  console.log('Next state:', store.getState());
  return result;
};

const timingMiddleware: Middleware = store => next => action => {
  const start = performance.now();
  const result = next(action);
  console.log(`${(action as any).type} took ${performance.now() - start}ms`);
  return result;
};

const store = createStore(
  rootReducer,
  applyMiddleware(loggerMiddleware, timingMiddleware)
);
```

| Middleware parameter | Description |
|----------------------|-------------|
| `store` | `{ getState, dispatch }` — the store API |
| `next` | Calls the next middleware (or the real `dispatch` if last) |
| `action` | The action being dispatched |

---

## compose

Composes functions from right to left. Used internally by `applyMiddleware`.

```typescript
import { compose } from '@headlesskit/state-management';

const enhance = compose(
  applyMiddleware(thunk),
  DevToolsExtension.instrument()
);

const store = createStore(rootReducer, enhance);
```

## bindActionCreators

Wraps action creator functions so every call is automatically dispatched.

```typescript
import { bindActionCreators } from '@headlesskit/state-management';

const actionCreators = {
  increment: () => ({ type: 'INCREMENT' as const }),
  decrement: () => ({ type: 'DECREMENT' as const }),
  add: (n: number) => ({ type: 'ADD' as const, payload: n }),
};

// Bind to dispatch
const actions = bindActionCreators(actionCreators, store.dispatch);

actions.increment();        // dispatches { type: 'INCREMENT' }
actions.add(5);             // dispatches { type: 'ADD', payload: 5 }
```

Pass a single action creator or a map of them:

```typescript
// Single
const boundIncrement = bindActionCreators(actionCreators.increment, store.dispatch);
boundIncrement(); // dispatches

// Map
const { increment, decrement } = bindActionCreators(actionCreators, store.dispatch);
```

## isAction

Type guard that returns `true` if a value is a plain object with a `type: string` property.

```typescript
import { isAction } from '@headlesskit/state-management';

isAction({ type: 'DO_THING' });          // true
isAction({ type: 'DO_THING', data: 1 }); // true
isAction('string');                       // false
isAction({ type: 42 });                   // false
isAction(null);                           // false
```

---

## isPlainObject

Returns `true` if the value was created by `{}` or `Object.create(null)` — not a class instance, array, or primitive.

```typescript
import { isPlainObject } from '@headlesskit/state-management';

isPlainObject({});                    // true
isPlainObject({ a: 1 });             // true
isPlainObject(Object.create(null));   // true
isPlainObject([]);                    // false
isPlainObject(new Map());             // false
isPlainObject(null);                  // false
```

## TypeScript Types

| Type | Description |
|------|-------------|
| `Action<T extends string>` | Plain action with a `type` field |
| `UnknownAction` | `Action` with any extra string-keyed properties |
| `AnyAction` | Deprecated — use `UnknownAction` |
| `ActionCreator<A, P>` | Function that returns an action |
| `ActionCreatorsMapObject` | Record of action creators |
| `Reducer<S, A, PreloadedState>` | `(state, action) => state` |
| `ReducersMapObject<S, A>` | Map of slice reducers |
| `Middleware<Ext, S, D>` | Middleware function signature |
| `MiddlewareAPI<D, S>` | `{ dispatch, getState }` passed to middleware |
| `Store<S, A>` | Redux store object |
| `StoreCreator` | Function that creates a store |
| `StoreEnhancer<Ext, StateExt>` | Wraps store creator to add capabilities |
| `Dispatch<A>` | Function to dispatch actions |
| `Unsubscribe` | Function returned by `store.subscribe` |

## Patterns

### Typed dispatch

```typescript
import type { Dispatch, UnknownAction } from '@headlesskit/state-management';

type AppAction =
  | { type: 'SET_USER'; user: User }
  | { type: 'LOGOUT' };

const store = createStore(rootReducer);
const dispatch = store.dispatch as Dispatch<AppAction>;

dispatch({ type: 'SET_USER', user: { id: 1, name: 'Alice' } });
dispatch({ type: 'LOGOUT' });
```

### Preloading state (SSR)

```typescript
// Server: serialize state
const preloadedState = await fetchInitialState();

// Client: hydrate
const store = createStore(rootReducer, preloadedState);
```

### Multiple enhancers

```typescript
import { createStore, applyMiddleware, compose } from '@headlesskit/state-management';

const store = createStore(
  rootReducer,
  compose(
    applyMiddleware(thunk, logger),
    (window as any).__REDUX_DEVTOOLS_EXTENSION__?.() ?? (x: any) => x
  )
);
```

> **Prefer `configureStore`** from `@headlesskit/state-management-toolkit` — it wires up DevTools, thunk middleware, and dev-mode invariant checks automatically.

## Observable

The store implements the [Observable spec](https://github.com/tc39/proposal-observable). You can subscribe with any Observable library:

```typescript
import { from } from 'rxjs';

const state$ = from(store as any);
state$.subscribe(state => console.log(state));
```
